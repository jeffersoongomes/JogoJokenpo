# Jokenpô do Jefferson 🎮✂️

Projeto acadêmico interativo desenvolvido para a disciplina de Análise e Desenvolvimento de Sistemas, trazendo uma versão personalizada do clássico jogo **Jokenpô (Pedra, Papel e Tesoura)**.

---

## 🚀 Funcionalidades
* **Interface Personalizada:** Título customizado com o nome do utilizador e plano de fundo exclusivo desenhado no Paint (`fundo.jpg`).
* **Arena de Confronto Visual:** Exibição dinâmica das jogadas do jogador contra o computador.
* **Mensagens Dinâmicas:** Alertas personalizados que mencionam o teu nome (Jefferson) em cada vitória, derrota ou empate.
* **Placar em Tempo Real:** Controlo automático de pontos e botões de reinício rápido.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** — Estrutura da página e elementos da interface.
* **CSS3** — Estilização moderna, flexbox, animações suaves e imagem de fundo responsiva.
* **JavaScript (ES6+)** — Lógica do jogo, manipulação do DOM e mapeamento de regras otimizado.
